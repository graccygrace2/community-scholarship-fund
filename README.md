# Community Scholarship Fund

## Overview

The Community Scholarship Fund is a blockchain-based platform that democratizes educational funding through decentralized community contributions and fair selection processes. This system empowers communities to support local students' educational goals while ensuring transparency and accountability in fund management.

## Description

Community-funded scholarship program supporting local students' educational goals through three core smart contracts that work together to create a comprehensive educational funding ecosystem.

## System Architecture

### Core Contracts

#### 1. Scholarship Pool (`scholarship-pool`)
- **Purpose**: Manage community contributions to educational scholarship funds
- **Key Features**:
  - Accept and track community donations
  - Maintain transparent fund balances
  - Enable secure fund withdrawals for approved scholarships
  - Track contribution history and statistics

#### 2. Student Selection (`student-selection`)  
- **Purpose**: Fair selection process for scholarship recipients based on need and merit
- **Key Features**:
  - Register student applications with academic and financial information
  - Implement fair scoring algorithms for need and merit assessment
  - Enable community voting on scholarship recipients
  - Maintain transparent selection records

#### 3. Progress Tracking (`progress-tracking`)
- **Purpose**: Track student academic progress and scholarship impact
- **Key Features**:
  - Monitor academic milestones and achievements
  - Track scholarship fund utilization
  - Generate impact reports for community transparency
  - Enable performance-based continued funding

## Key Benefits

- **Transparency**: All transactions and decisions are recorded on the blockchain
- **Community Driven**: Local community members control funding decisions
- **Fair Selection**: Merit and need-based algorithms ensure equitable distribution
- **Progress Monitoring**: Continuous tracking of student success and fund impact
- **Accountability**: Smart contracts enforce proper fund usage and reporting

## Technical Stack

- **Blockchain**: Stacks Blockchain
- **Smart Contract Language**: Clarity
- **Development Framework**: Clarinet
- **Testing**: Clarinet testing framework

## Getting Started

### Prerequisites
- Clarinet CLI installed
- Node.js and npm
- Git

### Installation
```bash
git clone https://github.com/graccygrace2/community-scholarship-fund.git
cd community-scholarship-fund
clarinet check
```

### Testing
```bash
clarinet test
```

## Contract Deployment

The contracts are designed to be deployed on the Stacks blockchain and can be tested locally using Clarinet's development environment.
